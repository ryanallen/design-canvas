Install the design canvas

These instructions are for an AI coding agent (Claude Code, Codex, Cursor and the like). Someone pasted this link to you because they want the design canvas in their project: one board that lays out every HTML prototype in a folder, so they can look at them side by side, click through them, edit them and comment on them. Every edit is written back into the prototype's own .html file.

If you can run commands, do each step yourself and tell the person what you did. If you cannot, walk them through it: give them one step at a time, the exact command to paste, and wait for them to say it worked before the next.

1. Check for Node

The canvas needs Node and nothing else: no package install, no build step, no account.

node --version

If that fails, ask them to install the LTS version from nodejs.org, then open a new terminal and try again. Do not go on without it.

2. Put the skill in the project

From the project's root folder, clone it into the folder you read skills from: .claude/skills for Claude Code, or the skills folder your own tool reads (many projects keep one at .agents/skills). The commands on this page use .agents/skills; change the path to the one you use.

git clone https://github.com/ryanallen/design-canvas .agents/skills/design-canvas

Without git, download the zip and unpack it so that .agents/skills/design-canvas/SKILL.md exists. If the project is a git repository, ask whether they want the skill committed with it or listed in .gitignore.

3. Find the prototypes

The canvas works on one folder: every .html file in it is a prototype. Ask which folder holds theirs, or look for one. If they have none yet, make an empty folder such as designs; the canvas opens as a whiteboard and they can draw a new screen on it with A.

4. Open it

node .agents/skills/design-canvas/scripts/canvas.mjs serve designs

Put their folder in place of designs. It prints the address it serves on: http://127.0.0.1:4410, or the next free port if that one is taken. Open it in their browser and leave the command running while they work; it answers only this computer.

Laying screens out at their real height needs a Chromium that Playwright can drive. The canvas finds one already on the machine. If it warns that it has none, every screen is drawn 1440 × 1000, which still works; to measure them, run npx playwright install chromium and serve again.

On Windows or a Mac they can instead double-click Design Canvas.cmd or Design Canvas.command in the skill's folder and pick the folder there.

5. Show them around

  1. A click on anything in a screen selects it; the toolbar over it changes text, colour, size and spacing, and the panel on the right has the rest.
  2. N makes a sticky note, C pins a comment, A draws a new screen.
  3. ▷ Play clicks through a prototype at full size.
  4. Shift+? lists every key.

6. Then, for you

Read .agents/skills/design-canvas/SKILL.md. It says how to build a canvas file to send to someone, how to read the comments and requests they leave for you on the board, and how to make edits through the canvas so they show up there at once. To update the skill later:

git -C .agents/skills/design-canvas pull
