Install the design canvas

These steps are for an AI coding agent, like Claude Code, Codex or Cursor. Someone gave you this link because they want the design canvas in their project. It puts all the HTML prototypes in a folder on one board. They can see them side by side, click through them, edit them and comment on them. Every edit is saved back into that prototype's own .html file.

If you can run commands, do each step yourself and tell the person what you did. If you can't, walk them through it one step at a time. Give them the exact command to paste, and wait until they say it worked before going on.

1. Check for Node

The canvas only needs Node. There's nothing else to install, nothing to build and no account.

node --version

If that fails, ask them to install the LTS version from nodejs.org, then open a new terminal and try again. Do not go on without it.

2. Put the skill in the project

From the project's root folder, clone it into the folder you read skills from. For Claude Code that's .claude/skills. Many projects keep one at .agents/skills, which is what the commands on this page use. Change the path if yours is different.

git clone https://github.com/ryanallen/design-canvas .agents/skills/design-canvas

Without git, download the zip and unpack it so that .agents/skills/design-canvas/SKILL.md exists. If the project uses git, ask whether they want the skill committed or added to .gitignore.

3. Find the prototypes

The canvas works on one folder, and every .html file in it is a prototype. Ask which folder has theirs, or look for it. If they don't have any yet, make an empty folder such as designs. The canvas opens as a blank whiteboard, and they can draw a new screen on it with A.

4. Open it

node .agents/skills/design-canvas/scripts/canvas.mjs serve designs

Put their folder in place of designs. It prints its address, usually http://127.0.0.1:4410 (or the next free port). Open that in their browser and leave the command running while they work. Only this computer can reach it.

To show each screen at its real height, the canvas uses a copy of Chromium that Playwright can drive, and it looks for one already on the computer. If it says it can't find one, every screen is shown 1440 × 1000. That still works. To get real heights, run npx playwright install chromium and start it again.

On Windows or a Mac, they can also double-click Design Canvas.cmd or Design Canvas.command in the skill's folder and pick their folder.

5. Show them around

  1. Click anything in a screen to select it. The toolbar above it changes text, color, size and spacing. The panel on the right has everything else.
  2. N makes a sticky note, C pins a comment, A draws a new screen.
  3. ▷ Play lets them click through a prototype at full size.
  4. Shift+? shows every keyboard shortcut.

6. Then read up

Read .agents/skills/design-canvas/SKILL.md. It explains how to make a canvas file to send to someone, how to read the comments and requests they leave for you on the board, and how to make your own edits through the canvas so they show up there right away. To update the skill later:

git -C .agents/skills/design-canvas pull
