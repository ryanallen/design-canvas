Design canvas

See every HTML prototype in a folder on one board. Click through them, change their text, styles and layout right where they are, comment on them and sketch around them. Every edit is saved back into the prototype's own .html file. All it needs is Node.

⬇ Download it ★ Star on GitHub View the code 
git clone https://github.com/ryanallen/design-canvas .agents/skills/design-canvas
node .agents/skills/design-canvas/scripts/canvas.mjs build <folder of prototypes>

Put it in your project's .agents/skills/design-canvas/ folder (or .claude/skills/design-canvas/), and your AI agent will read SKILL.md. No terminal? Double-click Design Canvas.cmd on Windows or Design Canvas.command on a Mac and pick a folder.
