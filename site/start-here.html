Design canvas

Every HTML prototype in a folder, on one board. View them, play them, edit their text, styles and structure by pointing at them, comment on them, and draw around them. Every edit is written back into the prototype's own .html. Node only, nothing to install.

⬇ Download it ★ Star on GitHub View the code 
git clone https://github.com/ryanallen/design-canvas .agents/skills/design-canvas
node .agents/skills/design-canvas/scripts/canvas.mjs build <folder of prototypes>

As a skill, it goes in a project's .agents/skills/design-canvas/ (or .claude/skills/design-canvas/), and an agent reads SKILL.md. Without a terminal, double-click Design Canvas.cmd (Windows) or Design Canvas.command (Mac) and pick a folder.
